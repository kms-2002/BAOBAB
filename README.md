## 🤖 2. AutoGen 기반 3대 핵심 AI 에이전트 구조

1. **Agent 1: 매칭 & 안심식당 에이전트 (Matching & Safety Restaurant Agent)**
   - 사용자 선호 조건(희망 메뉴, 성별, 대화 성향, 유학생 허용) 및 GPS 위치 분석
   - 두 사용자의 **중간 지점 좌표 자동 도출**
   - **공공데이터 '안심식당' API**를 호출하여 최적의 중간지점 검증 제휴 식당 및 혜택(음료 서비스/할인) 추천
2. **Agent 2: 다국어 소통 & 중재 에이전트 (Multilingual Communication & Mediation Agent)**
   - 저지연 실시간 한/영 통번역 스트리밍 처리
   - 초면의 어색함을 깨기 위한 **'프로필 기반 아이스브레이킹 대화 카드'** 동적 생성
3. **Agent 3: 가디언 & 신뢰도 에이전트 (Guardian & Credibility Agent)**
   - 실시간 채팅 내 목적 외 언행(포교, 영업, 금전 요구 등) 사전 센싱 ➔ 즉시 경보 알림
   - 식사 완료 후 상호 매너 평가 및 노쇼 여부를 반영해 **'바오밥 나무 레벨(신뢰도 1~5단계)'** 동적 갱신
   - 안심식당 현장 SOS 긴급 호출 시스템 연동

| **Q1. 혼밥 시 외로움/어색함 경험** | **71.9%** | 1:1 소셜 다이닝 동행 매칭 시스템 제공 |
| **Q2. 2인 이상 메뉴 주문 포기** | **71.9%** | 부대찌개, 닭갈비, 삼겹살 등 2인 메뉴 전용 매칭 |

## 💻 5. 프로젝트 구조 (Project Structure)

```
BAOBAB/
├── server/
│   ├── server.js               # Express 메인 REST API 서버 (Port: 3000)
│   ├── agents/
│   │   ├── agent1_matching.js    # Agent 1: GPS 중간지점 & 공공 안심식당 로직
│   │   ├── agent2_translation.js # Agent 2: 저지연 실시간 통번역 & 대화카드 Generator
│   │   └── agent3_guardian.js    # Agent 3: 가디언 언행 검수 & 나무 레벨 계산기
│   └── data/
│       ├── safety_restaurants.json # 진주 대학가 안심식당 공공데이터 DB
│       └── users.json            # 사용자 및 2단계 인증 프로필 DB
├── public/
│   ├── index.html              # ALIO 테마 아이폰 17 Pro 모바일 웹 UI
│   └── app.js                  # 백엔드 REST API 실시간 통신 클라이언트
├── .gitignore
├── package.json
└── README.md
```
